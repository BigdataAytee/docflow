# Provider logos for DocFlow

Eleven provider marks, from the Simple Icons project (v16.32.0), coloured with each brand's own hex.

## What these are
Simplified single-colour brand glyphs. The Simple Icons SVG files are released under CC0, but
**the brands themselves remain trademarks of their owners** — CC0 covers the drawing, not the right
to use the mark. Use is subject to each owner's guidelines.

## Recommended use
- Settings "How you get paid" list: fine for identifying a service next to its name.
- Printed PDFs: NOT yet — pending a per-provider guidelines review (see PLAN.md).

## Dark mode
These are not provider-supplied dark variants. Do not invert or recolour them. In dark mode,
render each inside the fixed 36px slot on a light tile so the brand colour stays true.

## Not included (no free source available) — fetch from the provider if wanted
Flutterwave, M-Pesa, MTN MoMo, Wave, UPI, GCash, bKash, PromptPay, OPay, PalmPay.
These keep the name-only fallback, which is the specified working state.

See provenance.json for per-file source, guidelines link and fetch date.

## Paystack (added)
Official mark from Paystack's own brand page (their earlier website, published on GitHub).
Check paystack.frontify.com in case the current mark has changed.

## Flutterwave — download these two yourself (2 clicks)
Official icon-only files from flutterwave.com/ng/press-kit:
- https://flutterwave.com/brand/Logo%20pack/Icon_FullColor.svg          -> save as flutterwave.svg
- https://flutterwave.com/brand/Logo%20pack/Icon_MonochromeInverted.svg -> save as flutterwave-dark.svg
Their rules: no outline, no filters or effects, no stretching or recolouring, use the supplied
inverted version on dark backgrounds, and never suggest Flutterwave sponsors or partners with you.
