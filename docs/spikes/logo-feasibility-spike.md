## The ladder (§O) — failure is a step down, not a stall

1. **On-device generative model** — requires passing this spike.
2. **Procedural concept engine** — algorithmic compositor, geometry grammars,
   name set locally in bundled Unicode-capable fonts. Runs offline on every
   tier. *Promoted to the build target if rung 1 fails.*
3. **Cloud generation, opt-in** — the §N consented carve-out, owner-disableable.
4. **Formal requirement revision** — presented with measurements, never a
   silent substitution.

## The rubric — written now, argued never

Twenty ideas means **twenty different core visual concepts or substantially
different compositions**, across at least five sets.

Does **not** count as distinct: palette, font, background, rotation, or
adding/removing the name from the same mark. Named and symbol-only entries in
the quota must not duplicate one another; a chosen concept may later offer both
formats without counting twice.

The **description** is the primary source of meaning. The name supplies brand
context and lettering — never an inferred industry that contradicts the
description. A clarifying question is allowed only when the description is
genuinely ambiguous between incompatible readings.

**Duplicate detection alone is insufficient.** Human review against this rubric
decides.

## Pass / fail

Rung 1 passes only if, **on the target phones, offline**, every one of these
holds:

- [ ] Twenty distinct concepts across five sets for each of the ten
      descriptions, under human review against the rubric above.
- [ ] "More ideas" never wraps around and never disguises a recolour as new
      artwork.
- [ ] Small-size legibility, clean edges, balanced weight, clear space, and
      light/dark usability.
- [ ] Non-Latin and accented names set correctly in the bundled fonts.
- [ ] Generation time, memory and thermal behaviour inside the same budgets as
      the AI spike.
- [ ] The §O definition of done: download once → airplane mode → new
      name/description → twenty concepts → select → generate a document
      containing it → force-kill → recover it.

Any unchecked box ⇒ **rung 2 is the build target**, recorded here with the
measurements that decided it.
